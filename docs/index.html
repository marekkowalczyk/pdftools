pdftools

A versioned suite of Unix tools for PDF document production. Each tool ships in its own repo. This bundle pins which releases belong together and installs them in one step.

Install the suite GitHub 
git clone https://github.com/marekkowalczyk/pdftools.git
cd pdftools && bash install.sh

Tools in the suite

pdfclean
Compress PDFs in-place via cpdfsqueeze
mdtopdf
Convert Markdown to PDF via Pandoc
pdfocr
OCR a PDF and embed the text layer
pdflogo
Stamp a logo onto a PDF
pdfstamp
Add a filename watermark
pdfrem
Remove stamped-on text
pdfbates
Add Bates numbers
pdfsecret
Add a confidentiality overlay
pdfa4
Normalize pages to A4

Suite releases are a bill of materials: when a tool gets a new release, the bundle pins that tag and ships a matching suite version. Current release: v1.0.0 (pdfa4, pdfocr pinned; others join as they ship).
